# Fluxwatch 目标

## 一句话
AI（Claude Code 经 reclaude、Mirasim Cloud）有时静默卡住，界面没提示、代理面板延迟还好看。Fluxwatch 让卡住看得见，并说清卡在哪一层：线路、上游服务、账号配额，还是本地在跑工具（不算卡）。

## 范围
- mac 和 Windows 都做，菜单栏 / 托盘常驻，明暗两套主题跟随系统。
- 只观测。切节点由人在 Clash 里自己切，工具只负责让切没切成、切完好没好看得见。
- 先盯 reclaude（`*.reclaude.ai`）和 Mirasim（`*.mirasim.ai`）；其余从「发现」面板里挑正在跑的流量加进来，加目标不改代码。
- 每条流量标出是哪个软件发的。
- 按节点记账：哪个节点今天卡了几次、卡多久，给续哪个机场做依据。

## 不做
- 不自动切节点、不改 Clash 配置、不重试请求。
- 不读、不存会话内容。

## 怎么算做完（v0.1）
1. 两个平台的 CI 绿，Release 里有 mac（arm64、amd64）和 Windows（amd64）的包。
2. 本机 mac 上：托盘图标四态对；断网或拔节点时 30 秒内转红并通知，面板写明层级和节点；跑本地长命令时显示「本地忙」不报警。
3. 发现面板列出正在跑的连接，带软件名和节点，一键加入监控、立即生效。
4. 命令行 `fluxwatch-cli watch` 能单独跑，状态变化逐行打印，写账本。
